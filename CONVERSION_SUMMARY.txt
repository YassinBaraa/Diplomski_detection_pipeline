## Key Changes from ROS 2 → ROS 1

| Component | ROS 2 | ROS 1 Noetic |
|-----------|--------|--------------|
| Node initialization | rclpy.init() + Node class | rospy.init_node() |
| Publishing | self.create_publisher() | rospy.Publisher() |
| Parameters | self.declare_parameter() | rospy.get_param() |
| Logging | self.get_logger().info() | rospy.loginfo() |
| Timers | self.create_timer() | rospy.Timer() |
| Timestamps | timestamp.to_msg() | rospy.Time.now() |
| Launch files | Python format (.launch.py) | XML format (.launch) |
| Build system | colcon build | catkin_make / catkin build |
| Workspace setup | install/setup.bash | devel/setup.bash |

## Building in Your Container

```bash
# 1. Add package to workspace
cd ~/catkin_ws/src
ln -s /path/to/detection_pipeline_ros .

# 2. Install dependencies
pip install -r src/detection_pipeline_ros/requirements.txt

# 3. Build
cd ~/catkin_ws
catkin_make
# or if using catkin build:
# catkin build detection_pipeline_ros

# 4. Run
source devel/setup.bash
roslaunch detection_pipeline_ros detection_pipeline.launch
```

## Running the Pipeline

### Start ROS master
```bash
roscore
```

### In another terminal, launch the detection pipeline
```bash
source ~/catkin_ws/devel/setup.bash
roslaunch detection_pipeline_ros detection_pipeline.launch \
  video_path:=/path/to/video.mp4 \
  model_path:=/path/to/model.pt
```

### Monitor topics
```bash
rostopic list
rostopic echo /detection/best_candidate
rostopic hz /detection/frame
```

## Architecture

The pipeline consists of:
1. **Source**: MP4 file or camera input
2. **Detection**: YOLO instance segmentation
3. **Tracking**: ByteTrack multi-object tracking
4. **Post-processing**:
   - Mask extraction (binary segmentation)
   - Distance heatmap (centerline detection)
   - Skeleton extraction (medial axis)
   - Candidate scoring (geometric + temporal stability)
   - Visualization (debug output)

All stages run sequentially in a single ROS 1 node.
